# Itology — Technology. Simplified.

Marketing website for Itology, a complete IT solutions provider.

Single-file static site (`index.html`) — no build step required. Ready for one-click deployment on Vercel.

## Deploy on Vercel

1. Import this repository at https://vercel.com/new
2. Framework preset: **Other** (static)
3. Build command: leave blank
4. Output directory: leave blank (root)
5. Deploy

## Local preview

Just open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

then visit `http://localhost:8080`.
